# Report schema

The following is the default structure. Enable or disable modules according to
the request; do not force irrelevant sections into the report.

1. 摘要与关键判断
2. 技术要解决的问题
3. 核心机制与概念边界
4. 技术路线和关键差异
5. 已经被证明的能力
6. 尚未被证明或容易被夸大的能力
7. 实验结果与性能边界
8. 工程应用、产品化和部署条件
9. 与替代技术的比较
10. 成本、可靠性、规模化和维护
11. 争议、负面证据和未解决问题
12. 技术成熟度与未来路线
13. 结论与行动建议
14. 证据附录、检索范围和术语表

Every major section should answer one question and contain a judgment. A
section may use the following argument unit:

```text
问题或现象 → 机制 → 代表性证据 → 适用条件 → 局限/反例 → 工程含义
```
